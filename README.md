# S3Sport

منصة لمتابعة الرياضة المحلية في سلطنة عُمان: فرق المناطق، والبطولات، والمباريات ونتائجها المباشرة. الواجهة بالعربية ومصممة للجوال أولاً.

## ماذا تقدم
- **للجمهور:**
  - مركز المباريات، والنتائج المباشرة دون تحديث الصفحة.
  - صفحات الفرق واللاعبين والبطولات، وجداول الترتيب، والهدافين.
  - الأخبار بالصور والفيديو.
  - متابعة الفرق واللاعبين والمباريات، مع إشعارات تصل للجهاز حتى والموقع مغلق.
  - يعمل كتطبيق قابل للتثبيت على الهاتف (PWA).
- **لمسؤول الفريق:**
  - تسجيل الفريق من «حساب جديد ← فريق»: الحساب وطلب الفريق في خطوة واحدة. بعد موافقة الإدارة يحصل على صلاحيات فريقه فوراً.
  - التحكم الكامل بفريقه فقط: الاسم والشعار والبيانات، وإضافة اللاعبين وتعديلهم وحذفهم.
  - إضافة مباريات فريقه الودية، ضد فرق المنصة أو فرق ضيفة غير مسجلة.
  - إدارة المباراة مباشرة: البداية، الأشواط، الأهداف، ركلات الجزاء، البطاقات، التبديلات.
- **لمسؤول البطولة:**
  - أنظمة البطولات: دوري، ومجموعات، وخروج المغلوب، ونظام مختلط.
  - جدولة تلقائية للمباريات، وترتيب يُعاد حسابه بعد كل نتيجة، ومعايير كسر تعادل قابلة للضبط.
- **للإدارة:**
  - مراجعة طلبات تسجيل الفرق، والمستخدمين والصلاحيات.
  - المناطق والمواسم والملاعب.
  - سجل العمليات، ولوحة إحصائيات.

## التقنيات
ASP.NET Core 8 MVC · Entity Framework Core 8 · SQL Server · ASP.NET Identity · SignalR · Bootstrap 5 RTL · Chart.js · SweetAlert2 · Web Push (VAPID) · Serilog

## التشغيل محلياً
المتطلبات: .NET SDK 8 و SQL Server (أو LocalDB).

```bash
cd S3Sport
cp appsettings.Development.example.json appsettings.Development.json
# عدّل الملف: ضع كلمة مرور لحساب المدير في SeedAdmin:Password (8 أحرف على الأقل وفيها رقم)
# وعدّل ConnectionStrings:DefaultConnection في appsettings.json إذا لم يكن SQL Server على الجهاز نفسه
dotnet run --launch-profile http
```

افتح http://localhost:5107 وسجّل الدخول بـ `admin@s3sport.om` وكلمة المرور التي وضعتها.

في بيئة التطوير تُنشأ قاعدة البيانات تلقائياً، ومعها الأدوار وحساب المدير وبيانات المناطق.

## الأمان
الملفات التالية لا تُرفع إلى المستودع:
- **`appsettings.Development.json`:** كلمة مرور التطوير.
- **`App_Data`:** مفاتيح التشفير، والمفتاح الخاص لإشعارات الأجهزة، والسجلات.
- **`wwwroot/uploads`:** الصور التي يرفعها المستخدمون.

في الإنتاج تُعرَّف الإعدادات السرية كمتغيرات بيئة، والتفاصيل في [دليل النشر](docs/DEPLOYMENT.md).
